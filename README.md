## 下单前先花两分钟：查一查你买的是不是“伪住宅”

判断真伪住宅，查一次 ASN 就够。拿到 IP 后用 whois 或 ipinfo 查它的 ASN 归属，对照下面这张表：

| 类型 | 常见ASN | 特征 |
| --- | --- | --- |
| 真住宅IP | AS7922（Comcast）、AS7018（AT&T）、AS6079（RCN） | 行为接近普通家庭用户，很少被平台标记为代理 |
| 伪住宅IP | AS2914（NTT）、AS3257（GTT）、AS3356（Lumen） | 本质是骨干网/机房，WHOIS 显示 backbone 或 transit，部分平台直接判为 proxy |
| 高风险共享IP | AS16276（OVH）、AS9009（M247）、AS24940（Hetzner） | 成百上千人共用，极易触发验证码和封号 |

具体操作分两步。下单前让商家给测试 IP，先查一遍 ASN；拿到正式 IP 后再查一次，因为有些商家测试 IP 和实际交付的不是同一批资源。顺手再看一眼有没有 Spamhaus 之类的黑名单记录——被标记过的 IP 即使能连上，实际可用性也很差。

这一步能帮你避开市面上最常见的一种坑：拿 NTT、GTT 这类 Tier-1 骨干网的 IP，包装成“静态住宅”来卖。从 ASN 上看，它们和真正的 Comcast 家庭宽带完全是两回事。

## 挂牌价之外，这四个细节影响你实际花的钱

价格标签只是起点，真正决定成本和体验的是下面几件事。

**独享还是共享。** 共享 IP 便宜，但同一条 IP 上谁违规，所有人跟着遭殃——别人触发风控，你的账号陪葬。长期业务优先独享，这笔钱不能省。

**“不限流量”的边界。** 不限流量一般指不按 GB 收费，不代表带宽无上限：有些端口套餐每个端口只给 6Mbps。另外不少商家附带公平使用条款，长期满速跑大流量可能被限速。买前把条款翻一遍，特别是打算挂采集任务的。

**线路档位。** 同一个美国 IP，普通线路晚高峰可能卡成幻灯片，回国优化线路（9929、CMIN2、CN2 GIA 这类）明显更稳。Resip 和 LisaHost 都按线路分档，价差在每月一二十元的量级——如果你在晚高峰跑业务，这笔钱值得花。

**测试与退款。** 各家政策差别很大：有的提供免费测试，有的明确不测不退（IPdodo 的静态住宅IP就写明了不提供测试、不支持退款）。下单前问清三件事：能不能先测、IP 被标记了能不能换、退款怎么算。
